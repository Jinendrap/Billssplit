# BillSplit MVP

## Goal

Make splitting restaurant and grocery bills easier.

## Workflow

1. Upload bill image
2. Extract bill items using AI
3. Review extracted items
4. Generate shareable link
5. Participants join with names
6. Participants select consumed items
7. Shared items are split equally
8. Tax and service charges can be split equally or ignored
9. Final amount is calculated for each participant

## MVP Features

- Upload bill
- OCR extraction
- Edit extracted items
- Shareable bill link
- Join by name
- Item selection
- Shared item splitting
- Tax toggle
- Service charge toggle
- Final breakdown

## Not Included

- Login
- Payments
- UPI
- Notifications
- Mobile app
- Restaurant integrations

## Success Metric

Split a real restaurant bill with 3+ people successfully.
